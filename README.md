# Portfolio - Florencia Molina
Este es mi portfolio personal, realizado como proyecto para la materia Programación Web de la Licenciatura en Sistemas de Información de la UNSJ. 

La idea es mostrar un poco sobre mí, algunos de los proyectos que fui haciendo y las tecnologías que estoy aprendiendo.

## Secciones
La página contiene:
- Inicio
- Sobre mí
- Proyectos
- Contacto
- Referencias

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Funcionalidades
Entre algunas de las funciones de la página se encuentran:
- Diseño responsive
- Navegación entre secciones
- Botón para volver arriba
- Efectos con JavaScript
- Mostrar y ocultar información
- Validación de formulario
- Año actualizado automáticamente
- Consumo de la API pública de GitHub
- Muestra de los últimos repositorios actualizados

## API utilizada
Para la parte de Servicios Web utilicé la API pública de GitHub.
La página consulta mis repositorios y muestra algunos datos como:
- nombre del repositorio
- descripción
- último push
- enlace al repositorio
